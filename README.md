# socialist-market-economy（社会主义市场经济）

维多利亚 3（Victoria 3）政治制度 MOD，加入以社会主义市场经济为核心的**三项新制度**，涵盖经济系统、权力分配与政体原理三大法律组。

---

## 📜 新增制度与完整效果

### 1️⃣ 社会主义市场经济（经济系统）

> 社会主义经济制度与市场经济相结合的经济运行方式

| 效果 | 数值 |
|:-----|:-----|
| 贷款利率 | **-25%** |
| 店主投资池效率 | **+45%** |
| 资本家投资池效率 | **+45%** |
| 农民投资池效率 | **+25%** |
| 私人建设分配 | **+85%** |
| 政府股息再投资 | **+1.0** |
| 公司数量上限 | **+10** |
| 强制集体化 | ✅ 启用 |
| 禁止无补偿国有化 | ✅ 启用 |
| 禁止法律 | 农奴制（serfdom） |

- **进步度**：100
- **解锁**：合作社所有制（council_republic）、人民代表大会
- **效果预览**：启用时提示"激进左翼经济警示"
- **AI 倾向**：合作社所有制国家强制推行权重 ×10

### 2️⃣ 人民民主专政（权力分配）

> 工人阶级领导的，以工农联盟为基础的，对人民实行民主和对敌人实行专政的国家制度

| 效果 | 数值 |
|:-----|:-----|
| 政府总票数合法性 | **+100** |
| 意识形态不一致合法性惩罚 | **-25%** |
| 权威（authority） | **+250** |
| 基础投票权 | **+20** |
| 政府内利益集团吸引力 | **+20%** |

- **进步度**：50
- **解锁科技**：政治鼓动（political_agitation）
- **施政前提**：统治者所属利益集团拥有政党，或国家无选举权
- **启用效果**：清除所有现有政党，仅保留唯一合法政党，政府改组为单一政党制
- **可能引发的政治运动**：普选权、无政府主义

### 3️⃣ 人民代表大会（政体原理）

> 国家的一切权力属于人民，按照民主集中制原则，由选民选举产生各级人民代表大会，行使国家权力

| 效果 | 数值 |
|:-----|:-----|
| 政府总票数合法性 | **+10** |
| 政府规模合法性 | **+1** |
| 意识形态不一致合法性惩罚 | **-10%** |
| 工会政治力量 | **+25%** |

- **进步度**：200
- **解锁科技**：社会主义（socialism）
- **不可用于**：特许公司政体
- **启用效果**：立宪主义意识形态者转化为共和主义者；提示"激进左翼政体警示"
- **贫民支持度**：+5%（贫困阶层）
- **AI 倾向**：共产主义/无政府主义/先锋主义统治者更倾向采纳
- **可能引发的政治运动**：总统共和制、议会共和制

## 📦 安装方法

1. 下载本仓库并解压
2. 复制整个文件夹到维多利亚 3 的 mod 目录：
   - **Windows**：`文档/Paradox Interactive/Victoria 3/mod/`
   - **Linux**：`~/.local/share/Paradox Interactive/Victoria 3/mod/`
3. 启动游戏，在启动器中勾选启用本 MOD
